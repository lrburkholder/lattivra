# Context

The project needs an independent identity suitable for an OKF Explorer and an optional Engineering Profile. It is a personal learning and portfolio project, initially hosted in the maintainer's GitHub account rather than a dedicated organization.

# Decision

**Decision ID:** D-001. **Approval:** provisional; the name is not reserved.

- Use **Lattivra** as the working umbrella name.
- Use **Lattivra Explorer** and **Lattivra Engineering Profile for OKF** for the separate deliverables.
- Use the proposed repository path `lrburkholder/lattivra` if and when it is created.
- Avoid calling ordinary OKF documents "Lattivra artifacts" merely because the Explorer indexes them.

# Rationale

A distinctive umbrella name allows the Explorer to stay general-purpose while the engineering profile remains independently usable. Formal trademark clearance is not a launch priority for this noncommercial portfolio project.

# Consequences

- The name is provisional and may change without changing artifact semantics.
- No GitHub organization is required initially.
- Do not claim that any GitHub, package, or trademark namespace has been reserved.
