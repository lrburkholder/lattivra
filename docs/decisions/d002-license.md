# Context

Lattivra is an open-source personal portfolio and learning project. Its components should be easy to study, reuse, and contribute to, without requiring commercial licensing or a copyleft distribution model.

# Decision

**Decision ID:** D-002. **Approval:** accepted.

- License project code under **Apache License 2.0**.
- Include the full license text in the repository's root `LICENSE` file.
- Use Apache-2.0 as the initial license for original published project documentation and profile text, unless a particular external contribution or asset requires separate treatment.

# Rationale

Apache-2.0 is permissive, widely understood, and includes an explicit patent grant. It meets the project's reuse and portfolio goals.

# Consequences

- Review license compatibility and attribution obligations before incorporating third-party source code or assets.
- Preserve required notices and license information for reused dependencies or adapted materials.
- Do not assume a dependency's license is changed by the Lattivra repository license.
