# Lattivra

Lattivra is an experimental, local-first, open-source project for exploring Open Knowledge Format (OKF) artifacts across independent sources. It also defines a minimal, optional Engineering Profile for OKF.

This is a **documentation starter**, not a functioning Explorer or a completed compatibility proof of concept. It is intended for a personal portfolio and engineering learning project.

- Start with [the OKF bundle index](index.md).
- Read the [Engineering Profile](profiles/engineering/profile.md).
- Review the [M0 implementation plan](docs/plans/m0-compatibility.md).

The Explorer must remain useful without the Engineering Profile; neither component depends on Battalion. Source files remain authoritative and the initial Explorer is read-only.
